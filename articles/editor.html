เข้าสู่ระบบไม่ได้? ตรวจสอบการตั้งค่า Firebase
  1. Firebase Authentication → Sign-in method → Google: เปิดใช้งานและกด Save
  2. Authentication → Settings → Authorized domains: ต้องมี thonpin.github.io และ github-thonpin.firebaseapp.com
  3. หากยังขึ้น auth/internal-error เปิด DevTools (F12) → Network แล้วตรวจการตอบกลับจาก identitytoolkit.googleapis.com โดยไม่แชร์ Token, OAuth code หรือ Request Payload
