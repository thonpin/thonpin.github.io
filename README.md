# thonpin.github.io

Public deployment repository for the personal developer portfolio at https://thonpin.github.io/.

This repository contains only browser-delivered HTML, CSS, JavaScript, search-indexing files and the GitHub Pages marker. Source code sent to browsers is publicly inspectable. Firebase Authentication and Firestore authorization are enforced by the deployed Firebase service, not by hiding client JavaScript.

Development documentation, automated tests, and Firestore administration configuration are maintained separately in a private development repository. Do not commit private keys, service account files, personal data, or access tokens here.
